From this example to the full application

Set it up through GitHub.

The complete Python engine runs in GitHub Codespaces. You work in a browser, and GitHub provides the computer. This website stays available as your guide.

  1. Open the repository

    Sign in to GitHub, then open grisheet/prediction-market-engine. The source, fixtures, tests and dependency lockfile are all there.

  2. Create a Codespace

    Use the button below. On GitHub, select Create codespace. The configuration installs Python dependencies and starts the full dashboard and API automatically.

    Open in GitHub Codespaces

  3. Open the running dashboard

    Wait for setup to finish. In Codespaces, open Ports, find 8501 / Prediction Market Dashboard, and use Open in Browser. Keep the forwarded port private.

  4. Explore, then stop the Codespace

    Read the markets, books, risk status and reports. Run the synthetic paper test. When finished, use Stop current codespace in the Codespaces menu. Your GitHub plan controls usage and any charges.

Know which part you are using.

This website
A setup guide, source results and a focused browser demo. Inputs stay in your tab.
The full application
The Python pricing and replay engine, SQLite records, protected controls, API and Streamlit interface. It runs inside Codespaces or on your own computer.
Real trading
Disabled. No verified live connectors, eligibility check or live-run authorization is included.

Keep the distinction clear

A discrepancy is a candidate.

The calculation buys actual ask depth, subtracts modeled fees and a separate movement reserve, then checks sizing and risk limits. Complementary outcomes need known payout coverage.

A price difference alone does not establish arbitrage. One leg can fail, liquidity can disappear, and resolution can take time. The full system keeps real trading disabled until its missing integrations and controls are verified.
