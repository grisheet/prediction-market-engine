Privacy Policy

What this website processes, where your inputs go, and which services are involved.

Browser calculations

Prices, quantities, fee assumptions and paper scenarios are processed in your browser. This website does not send demo inputs to the project maintainer, a trading venue or an analytics service. The demo does not request account credentials. Inputs and the stop control stay in memory in the current tab and reset when the page reloads.

Storage and downloads

This website sets no application cookies and does not use IndexedDB. If you explicitly choose Light or Dark, it stores only that theme preference in localStorage under the key pm-engine.theme. System mode removes that saved choice and follows your device’s color preference, including changes while the page is open. No financial inputs are saved. If browser storage is blocked, theme changes still work for the current page. A downloaded JSON report is generated in your browser and saved only where you choose. The website does not upload that report. The original sample reports are public synthetic files in the GitHub repository.

Hosting information

GitHub Pages serves this website and may process technical information such as your IP address and request metadata under GitHub’s Privacy Statement. No third-party analytics, advertising pixels, embedded videos, remote fonts or trading API requests are included in this website. The decimal arithmetic library is served from this repository.

External links and Codespaces

Links to the source repository, issues, Actions and Codespaces take you to GitHub. GitHub may require sign-in and apply its own privacy and billing terms. Data and records created inside the full Python application are separate from this website and remain in that application’s environment unless you export or share them.

Public contributions

Information you deliberately publish in repository issues, comments or code follows GitHub’s visibility and retention rules. Avoid publishing personal information, financial account data or secrets. The maintainer cannot delete copies already downloaded by others or control GitHub’s hosting logs.

Questions and updates

For project-specific privacy questions, open a GitHub issue without sensitive details. Requests about GitHub account or hosting data should follow GitHub’s own privacy channels. This policy will be updated if the website’s collection or storage behavior changes.
